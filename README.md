# 🐚 Shell Scripting Notes & Practice

Este repositório contém meus registros de estudos, anotações detalhadas e exercícios práticos sobre **Shell Scripting** e administração de sistemas Linux.

O objetivo aqui é documentar a jornada de aprendizado de forma clara, organizada e modular — funcionando tanto como um "segundo cérebro" para consultas futuras quanto como um portfólio prático de conceitos dominados.

---

## 🛠️ Tecnologias & Ferramentas
- **SO:** Linux (Debian)
- **Shell:** Bash (`/bin/bash`)
- **Terminal:** BlackBox
- **Editor:** Neovim
- **Documentação:** Markdown / Obsidian
